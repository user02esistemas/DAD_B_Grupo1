# Postman

Carpeta para pruebas de la API REST.

Estructura:

```text
collections/     Colecciones exportadas de Postman.
environments/    Variables de entorno, por ejemplo host local y token.
```

Importar en Postman:

```text
collections/EconoSalud-API.postman_collection.json
environments/EconoSalud-Local.postman_environment.json
```
