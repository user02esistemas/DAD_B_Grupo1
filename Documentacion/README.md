# Documentacion

Documentacion tecnica del sistema en formato Markdown.

Contenido permitido en este repositorio:

```text
arquitectura.md
estructura-proyecto.md
api-rest-endpoints.md
contratos-rmi.md
frontend-web.md
guia-instalacion.md
guia-instalacion-ejecucion.md
guia-para-desarrolladores.md
seguridad-permisos.md
permisos-db.md
```

No subir aqui:

```text
Informe Word
Capturas pesadas
Videos
Anexos finales del curso
Archivos comprimidos
```

La entrega academica final debe mantenerse fuera del repositorio del sistema.
